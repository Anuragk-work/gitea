<h1>Packages & Actions API</h1>
<h1 id="packages-actions-api">Packages &amp; Actions API</h1>
<p>Gitea exposes two large families of HTTP endpoints that live <strong>outside</strong> the versioned <code>/api/v1</code> tree described in <a href="api-v1-overview.html">API v1 Overview</a>:</p>
<ul>
<li><strong><code>routers/api/packages/*</code></strong> — ecosystem-specific package-registry protocol endpoints (npm, Maven, Docker/OCI, NuGet, Cargo, PyPI, Debian, RPM, Conan, Helm, Go proxy, Terraform state, etc.), mounted at <code>/api/packages/{owner}/...</code> and, for the OCI container registry, at the site root <code>/v2</code>.</li>
<li><strong><code>routers/api/actions/*</code></strong> — the machine-to-machine API used by Actions <strong>runners</strong> (registration, task polling, log streaming) and by workflow steps/jobs to upload <strong>artifacts</strong> and <strong>job summaries</strong>, mounted at <code>/api/actions*</code>.</li>
</ul>
<p>Both families sit alongside (not inside) <code>routers/api/v1</code>, are mounted directly by <a href="../../routers/init.go"><code>routers/init.go</code></a>, and use their own authentication schemes rather than the standard API token/OAuth2 chain used by <code>/api/v1</code> — because their clients are package-manager CLIs (<code>npm</code>, <code>cargo</code>, <code>docker</code>, <code>dotnet nuget</code>, ...) and Actions runner binaries, not typical REST API consumers.</p>
<blockquote>
<p>This page complements <a href="api-v1-overview.html">API v1 Overview</a>, which documents the Gitea-native package <strong>management</strong> API at <code>/api/v1/packages/{username}/...</code> (list/inspect/delete packages — used by the web UI and <code>tea</code> CLI). This page documents the <strong>registry protocol</strong> implementations that the package-manager clients themselves talk to.</p>
</blockquote>
<h2 id="mounting-in-routersinitgo">Mounting in <code>routers/init.go</code><a href="#mounting-in-routersinitgo" class="heading-anchor" aria-label="Link">#</a></h2>
<pre class="highlight"><code class="language-go">func NormalRoutes() *web.Router {
    r := web.NewRouter()
    ...
    r.Mount("/", web_routers.Routes())
    r.Mount("/api/v1", apiv1.Routes())
    r.Mount("/api/internal", private.Routes())

    if setting.Packages.Enabled {
        // This implements package support for most package managers
        r.Mount("/api/packages", packages_router.CommonRoutes())
        // This implements the OCI API; this container registry "/v2" endpoint must be
        // in the root of the site (reverse proxies must map https://host/v2 to Gitea).
        r.Mount("/v2", packages_router.ContainerRoutes())
    }

    if setting.Actions.Enabled {
        prefix := "/api/actions"
        r.Mount(prefix, actions_router.Routes(prefix))

        prefix = "/api/actions_pipeline"
        r.Mount(prefix, actions_router.ArtifactsRoutes(prefix))
        prefix = actions_router.ArtifactV4RouteBase // "/twirp/github.actions.results.api.v1.ArtifactService"
        r.Mount(prefix, actions_router.ArtifactsV4Routes(prefix))
    }
    ...
}</code></pre>
<p>Both the packages routes and the Actions routes are <strong>feature-flagged</strong>: they are only mounted when <code>[packages].ENABLED</code> / <code>[actions].ENABLED</code> are true in <code>app.ini</code> (<code>setting.Packages.Enabled</code>, <code>setting.Actions.Enabled</code>). When disabled, the corresponding paths 404 via the global <code>NotFound</code> handler at the bottom of <code>NormalRoutes()</code>.</p>

<h3 id="commonroutes-non-container-ecosystems"><code>CommonRoutes()</code> — Non-Container Ecosystems<a href="#commonroutes-non-container-ecosystems" class="heading-anchor" aria-label="Link">#</a></h3>
<p><code>packages_router.CommonRoutes()</code> (in <code>routers/api/packages/api.go</code>) returns a <code>*web.Router</code> mounted at <code>/api/packages</code> and shared by every ecosystem <strong>except</strong> the OCI container registry. Its top-level shape is:</p>
<pre class="highlight"><code class="language-go">func CommonRoutes() *web.Router {
    r := web.NewRouter()
    r.AfterRouting(context.PackageContexter())

    verifyAuth(r, []auth.Method{
        &amp;auth.OAuth2{},
        &amp;auth.Basic{},
        &amp;nuget.Auth{},
        &amp;Auth{},      // routers/api/packages/auth.go — Bearer-token auth used by conan/container
        &amp;chef.Auth{},
    }, verifyAuthOptions{})

    r.Group("/{username}", func() {
        r.Group("/alpine", ...)     // reqPackageAccess(read) at group level, write-gated per mutating route
        r.Group("/arch", ...)
        r.Group("/cargo", ...)
        r.Group("/chef", ...)
        r.Group("/composer", ...)
        r.Group("/conan", ...)
        r.Group("/cran", ...)
        r.Group("/debian", ...)
        r.Group("/go", ...)         // Go module proxy (goproxy)
        r.Group("/generic", ...)
        r.Group("/helm", ...)
        r.Group("/maven", ...)
        r.Group("/nuget", ...)
        r.Group("/npm", ...)
        r.Group("/pub", ...)
        r.Group("/pypi", ...)
        r.Group("/rubygems", ...)
        r.Group("/swift", ...)
        r.Group("/terraform/state/{name}", ...)
        r.Group("/vagrant", ...)
    }, context.UserAssignmentWeb(), context.PackageAssignment())

    return r
}</code></pre>
<p>Every <code>/{username}/&lt;ecosystem&gt;</code> sub-tree is protected by:</p>
<ol>
<li><strong><code>context.UserAssignmentWeb()</code></strong> — resolves <code>{username}</code> into <code>ctx.ContextUser</code> (the package owner — a user or organization), 404-ing if it doesn't exist.</li>
<li><strong><code>context.PackageAssignment()</code></strong> — computes <code>ctx.Package</code> (<code>*context.Package{Owner, AccessMode, Descriptor}</code>) by determining the caller's access mode against that owner (public/private/limited visibility rules, collaborator/team permissions for orgs) — implemented in <code>services/context/package.go</code>.</li>
<li><strong><code>reqPackageAccess(perm.AccessMode)</code></strong> — a router-local middleware (<code>routers/api/packages/api.go</code>) applied per-group (read) and per-mutating-route (write) that:</li>
<li>if the caller authenticated with a <strong>personal access token</strong>, requires the token to carry <code>read:package</code> / <code>write:package</code> scope (<code>AccessTokenScopeReadPackage</code> / <code>AccessTokenScopeWritePackage</code>);</li>
<li>additionally rejects <strong>public-only</strong> scoped tokens against non-public package owners;</li>
<li>otherwise falls back to <code>ctx.Package.AccessMode</code>, allowing site admins through regardless.</li>
</ol>
<pre class="mermaid">graph TD
    A["/api/packages/{username}/<ecosystem>/..."] --> B["context.PackageContexter() (AfterRouting)"]
    B --> C["verifyAuth: OAuth2 / Basic / nuget.Auth / packages.Auth / chef.Auth"]
    C --> D["context.UserAssignmentWeb() -> ctx.ContextUser"]
    D --> E["context.PackageAssignment() -> ctx.Package{Owner, AccessMode}"]
    E --> F["reqPackageAccess(Read|Write)"]
    F --> G["ecosystem handler (e.g. npm.UploadPackage)"]
    G --> H["services/packages: CreatePackageAndAddFile / AddFileToExistingPackage / ..."]
    H --> I["models/packages: Package / PackageVersion / PackageFile / PackageBlob"]</pre>

<p><code>packages.Auth.Verify()</code> special-cases two synthetic identities:</p>
<ul>
<li><strong>Ghost user</strong> (<code>user_model.GhostUserID</code>) — only honored when <code>AllowGhostUser: true</code> (used by the container registry to allow anonymous/public pulls with a short-lived scoped token).</li>
<li><strong>Actions user</strong> (<code>user_model.ActionsUserID</code>) — lets an Actions job authenticate as the special Actions bot identity when publishing packages from CI (<code>ACTIONS_RUNTIME_TOKEN</code>-style flow), carrying an <code>ActionsUserTaskID</code> for auditing.</li>
</ul>
<p>If the parsed token carries a <code>Scope</code>, <code>Auth.Verify()</code> stashes <code>IsApiToken=true</code> / <code>ApiTokenScope</code> into the auth <code>DataStore</code>, which is exactly what <code>reqPackageAccess()</code> later inspects to enforce <code>read:package</code>/<code>write:package</code> scope — the same scope-checking logic used by <code>/api/v1</code>, reused here without going through the <code>/api/v1</code> router at all.</p>
<h3 id="containerroutes-oci-docker-registry"><code>ContainerRoutes()</code> — OCI / Docker Registry<a href="#containerroutes-oci-docker-registry" class="heading-anchor" aria-label="Link">#</a></h3>
<p>The container (Docker/OCI) registry cannot live under <code>/api/packages</code> because the <a href="https://github.com/opencontainers/distribution-spec/blob/main/spec.html">OCI Distribution Spec</a> hard-codes the path prefix <code>/v2/</code>. <code>packages_router.ContainerRoutes()</code> therefore returns a router mounted at the <strong>site root</strong> <code>/v2</code>:</p>
<pre class="highlight"><code class="language-go">func ContainerRoutes() *web.Router {
    r := web.NewRouter()
    r.AfterRouting(context.PackageContexter())

    verifyAuth(r, []auth.Method{
        &amp;auth.Basic{},
        &amp;Auth{AllowGhostUser: true}, // lets anonymous pulls of public images get a Ghost-user token
    }, verifyAuthOptions{
        afterAuthCallback: func(ctx *context.Context, err error) {
            if err != nil {
                container.APIUnauthorizedError(ctx) // OCI-shaped 401 + WWW-Authenticate, not a generic redirect
            }
        },
    })

    r.Get("", container.ReqContainerAccess, container.DetermineSupport)      // GET /v2/ — API version probe
    r.Group("/token", func() {
        r.Get("", container.Authenticate)                 // docker login token endpoint
        r.Post("", container.AuthenticateNotImplemented)
    })
    r.Get("/_catalog", container.ReqContainerAccess, container.GetRepositoryList)
    r.Group("/{username}", func() {
        r.PathGroup("/*", func(g *web.RouterPathGroup) {
            g.MatchPath("POST",   "/&lt;image:*&gt;/blobs/uploads", reqPackageAccess(perm.AccessModeWrite), container.VerifyImageName, container.PostBlobsUploads)
            g.MatchPath("GET",    "/&lt;image:*&gt;/tags/list", container.VerifyImageName, container.GetTagsList)
            // ... blob upload session (GET/PATCH/PUT/DELETE by upload UUID) ...
            g.MatchPath("HEAD",   "/&lt;image:*&gt;/blobs/&lt;digest&gt;", container.VerifyImageName, container.HeadBlob)
            g.MatchPath("GET",    "/&lt;image:*&gt;/blobs/&lt;digest&gt;", container.VerifyImageName, container.GetBlob)
            g.MatchPath("DELETE", "/&lt;image:*&gt;/blobs/&lt;digest&gt;", container.VerifyImageName, reqPackageAccess(perm.AccessModeWrite), container.DeleteBlob)
            g.MatchPath("HEAD",   "/&lt;image:*&gt;/manifests/&lt;reference&gt;", container.VerifyImageName, container.HeadManifest)
            g.MatchPath("GET",    "/&lt;image:*&gt;/manifests/&lt;reference&gt;", container.VerifyImageName, container.GetManifest)
            g.MatchPath("PUT",    "/&lt;image:*&gt;/manifests/&lt;reference&gt;", container.VerifyImageName, reqPackageAccess(perm.AccessModeWrite), container.PutManifest)
            g.MatchPath("DELETE", "/&lt;image:*&gt;/manifests/&lt;reference&gt;", container.VerifyImageName, reqPackageAccess(perm.AccessModeWrite), container.DeleteManifest)
        })
    }, container.ReqContainerAccess, context.UserAssignmentWeb(), context.PackageAssignment(), reqPackageAccess(perm.AccessModeRead))

    return r
}</code></pre>
<p>Key differences from <code>CommonRoutes()</code>:</p>
<ul>
<li><strong><code>/{image:*}</code> path-group matching</strong> — image names are themselves slash-delimited (e.g. <code>myorg/backend/api</code>), so the router uses <code>r.PathGroup</code> + <code>g.MatchPath</code>/<code>g.MatchPattern</code> instead of a fixed segment count.</li>
<li><strong>Blob-upload session lifecycle</strong> — <code>POST .../blobs/uploads</code> starts a resumable upload and returns a <code>{uuid}</code>; subsequent <code>GET</code>/<code>PATCH</code>/<code>PUT</code>/<code>DELETE</code> on <code>.../blobs/uploads/{uuid}</code> (matched via <code>g.PatternRegexp</code>) stream/append/finalize/cancel the upload, per the OCI chunked-upload protocol.</li>
<li><strong><code>container.APIUnauthorizedError</code></strong> replaces the default <code>afterAuthCallback</code> so that failed auth returns the OCI-mandated <code>401</code> + <code>WWW-Authenticate: Bearer realm="…"</code> header shape that <code>docker</code>/<code>podman</code> expect, rather than a Gitea-style JSON error.</li>
<li><strong>Content Discovery / Referrers</strong> (OCI 1.1 <code>GET /v2/.../referrers/{digest}</code>) is explicitly marked <code>// TODO: not implemented yet</code> in the source.</li>
</ul>
<h2 id="actions-api-routersapiactions">Actions API (<code>routers/api/actions</code>)<a href="#actions-api-routersapiactions" class="heading-anchor" aria-label="Link">#</a></h2>
<p>The Actions API is not a single router — <code>routers/api/actions.Routes(prefix)</code> only wires up the <strong>runner</strong> gRPC/Connect service and the <strong>ping</strong> health-check service. Artifact upload/download and job-summary upload are separate routers mounted at different prefixes, because they use plain REST semantics rather than Connect RPC.</p>
<pre class="highlight"><code class="language-go">// routers/api/actions/actions.go
func Routes(prefix string) *web.Router {
    m := web.NewRouter()

    path, handler := ping.NewPingServiceHandler()
    m.Post(path+"*", http.StripPrefix(prefix, handler).ServeHTTP)

    path, handler = runner.NewRunnerServiceHandler()
    m.Post(path+"*", http.StripPrefix(prefix, handler).ServeHTTP)

    return m
}</code></pre>
<p>Mounted (see above) at <code>/api/actions</code>, this exposes two <a href="https://connectrpc.com/">Connect RPC</a> (gRPC/gRPC-Web/JSON-over-HTTP-compatible) services generated from the <code>actions-proto-go</code> protobuf definitions:</p>
<h3 id="pingpingservice"><code>ping.PingService</code><a href="#pingpingservice" class="heading-anchor" aria-label="Link">#</a></h3>
<p>A trivial health/handshake check (<code>Ping(PingRequest{Data}) -&gt; PingResponse{Data}</code>) used by runners to verify connectivity and protocol compatibility before registering.</p>
<h3 id="runnerrunnerservice"><code>runner.RunnerService</code><a href="#runnerrunnerservice" class="heading-anchor" aria-label="Link">#</a></h3>

<tbody>

<td><code>Register</code></td>
<td>Exchange a one-time <strong>registration token</strong> (<code>actions_model.GetRunnerToken</code>) for a persistent runner identity (<code>UUID</code> + <code>Token</code>). Validates the token is active and, if scoped to an owner/repo, that it still exists. Creates the <code>ActionRunner</code> row and marks the registration token used.</td>
</tr>
<tr>

<p>Every RPC <strong>except <code>Register</code></strong> is authenticated by a Connect <strong>unary interceptor</strong> (<code>withRunner</code> in <code>interceptor.go</code>) rather than the standard Gitea auth middleware chain, because Connect RPC doesn't route through <code>services/context</code>:</p>
<pre class="highlight"><code class="language-go">var withRunner = connect.WithInterceptors(connect.UnaryInterceptorFunc(func(unaryFunc connect.UnaryFunc) connect.UnaryFunc {
    return func(ctx context.Context, request connect.AnyRequest) (connect.AnyResponse, error) {
        if getMethodName(request) == "Register" {
            return unaryFunc(ctx, request) // no runner identity to check yet
        }
        uuid := request.Header().Get("x-runner-uuid")
        token := request.Header().Get("x-runner-token")

        runner, err := actions_model.GetRunnerByUUID(ctx, uuid)
        // ... constant-time token-hash comparison, else Unauthenticated ...

        // Debounced LastActive/LastOnline heartbeats to bound DB write volume
        // from high-frequency UpdateTask/UpdateLog calls.
        ctx = context.WithValue(ctx, runnerCtxKey{}, runner)
        return unaryFunc(ctx, request)
    }
}))</code></pre>
<p>The runner identifies itself on every call via the <code>x-runner-uuid</code> / <code>x-runner-token</code> headers; the interceptor validates the token hash with <code>crypto/subtle.ConstantTimeCompare</code> (timing-attack resistant) and injects the resolved <code>*actions_model.ActionRunner</code> into the request context via <code>runner.GetRunner(ctx)</code> for handlers to use. <code>LastActive</code>/<code>LastOnline</code> timestamps are updated but <strong>debounced</strong> (<code>ShouldPersistLastActive</code>/<code>ShouldPersistLastOnline</code>) since <code>UpdateTask</code>/<code>UpdateLog</code> can fire many times per second during log streaming — writing on every call would be a major source of database load.</p>

<h3 id="artifacts-job-summaries-artifactsroutes-artifactsv4routes">Artifacts &amp; Job Summaries (<code>ArtifactsRoutes</code>, <code>ArtifactsV4Routes</code>)<a href="#artifacts-job-summaries-artifactsroutes-artifactsv4routes" class="heading-anchor" aria-label="Link">#</a></h3>
<p>Unlike the runner protocol, artifact upload/download reimplements (a subset of) the <strong>GitHub Actions Artifacts REST API</strong>, because <code>actions/upload-artifact</code>/<code>actions/download-artifact</code> and the <code>actions/toolkit</code> runtime speak plain HTTP/JSON, not Connect RPC.</p>
<p><strong>v1/legacy protocol</strong> — <code>ArtifactsRoutes(prefix)</code>, mounted at <code>/api/actions_pipeline</code>:</p>
<pre class="highlight"><code class="language-go">const artifactRouteBase = "/_apis/pipelines/workflows/{run_id}/artifacts"

func ArtifactsRoutes(prefix string) *web.Router {
    m := web.NewRouter()
    m.AfterRouting(ArtifactContexter())

    r := artifactRoutes{prefix: prefix, fs: storage.ActionsArtifacts}

    m.Group(artifactRouteBase, func() {
        m.Combo("").Get(r.listArtifacts).Post(r.getUploadArtifactURL).Patch(r.confirmUploadArtifact)
        m.Put("/{artifact_hash}/upload", r.uploadArtifact)
        m.Get("/{artifact_hash}/download_url", r.getDownloadArtifactURL)
        m.Get("/{artifact_id}/download", r.downloadArtifact)
    })

    m.Put(jobSummaryRouteBase, uploadJobSummary) // GITHUB_STEP_SUMMARY equivalent
    return m
}</code></pre>
<p>Flow: <code>POST .../artifacts</code> (with <code>{"Type":"actions_storage","Name":"artifact"}</code>) returns a <code>fileContainerResourceUrl</code>; the client then <code>PUT</code>s one or more content-hash-addressed chunks to <code>.../artifacts/{artifact_hash}/upload</code> (validated with <code>x-tfs-filelength</code>/<code>content-range</code>/<code>x-actions-results-md5</code> headers) and finally <code>PATCH</code>es the collection endpoint to merge chunks and persist the artifact to <code>storage.ActionsArtifacts</code>. Downloads reverse the process: <code>GET .../artifacts</code> lists available artifacts with a <code>fileContainerResourceUrl</code> per artifact, <code>GET .../artifacts/{artifact_id}/download</code> streams the file.</p>
<p><strong>v4 / Twirp protocol</strong> — <code>ArtifactsV4Routes(prefix)</code>, mounted at <code>ArtifactV4RouteBase = "/twirp/github.actions.results.api.v1.ArtifactService"</code> — implements the newer <a href="https://twitchtv.github.io/twirp/">Twirp</a>-style JSON-RPC-over-HTTP protocol that current <code>actions/upload-artifact@v4</code>/<code>download-artifact@v4</code> actions use:</p>
<pre class="highlight"><code class="language-go">func ArtifactsV4Routes(prefix string) *web.Router {
    m := web.NewRouter()
    r := artifactV4Routes{prefix: prefix, fs: storage.ActionsArtifacts}

    m.Group("", func() {
        m.Post("CreateArtifact", r.createArtifact)
        m.Post("FinalizeArtifact", r.finalizeArtifact)
        m.Post("ListArtifacts", r.listArtifacts)
        m.Post("GetSignedArtifactURL", r.getSignedArtifactURL)
        m.Post("DeleteArtifact", r.deleteArtifact)
    }, ArtifactContexter())
    m.Group("", func() {
        m.Put("UploadArtifact", r.uploadArtifact)
        m.Get("DownloadArtifact", r.downloadArtifact)
    }, ArtifactV4Contexter())

    return m
}</code></pre>
<p><code>CreateArtifact</code>/<code>FinalizeArtifact</code>/<code>GetSignedArtifactURL</code> operate on the standard <code>*ArtifactContext</code> (task resolved via the Actions runtime token used by the workflow job), while <code>UploadArtifact</code>/<code>DownloadArtifact</code> use a separate <code>ArtifactV4Contexter()</code> because those two endpoints are reached via a <strong>signed URL</strong> (<code>buildSignature</code>/<code>buildArtifactURL</code>, HMAC-style signature over <code>endpoint + expires + artifactName + taskID + artifactID</code>) rather than the runtime token — the signed URL is what <code>GetSignedArtifactURL</code> hands back to the workflow runner so it can <code>PUT</code>/<code>GET</code> the blob directly without re-authenticating.</p>
<p><strong>Job summaries</strong> (<code>job_summary.go</code>) — <code>PUT /api/actions_pipeline/_apis/pipelines/workflows/{run_id}/jobs/{job_id}/steps/{step_index}/summary</code> implements the <code>GITHUB_STEP_SUMMARY</code> mechanism: a workflow step writes Markdown to a special file, the runner <code>PUT</code>s its content here, and Gitea stores it via <code>actions_model.UpsertActionRunJobSummary</code> (capped by <code>MaxJobSummarySize</code>, with an aggregate-size limit <code>ErrJobSummaryAggregateExceeded</code>); an <strong>empty body clears</strong> the previously stored summary for that step (<code>DeleteActionRunJobSummary</code>). Only <code>Content-Type: text/markdown</code> (or no/<code>application/octet-stream</code> content type, defaulted to markdown) is accepted.</p>
