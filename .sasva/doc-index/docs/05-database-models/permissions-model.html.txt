<h1>Permissions Model</h1>
<h1 id="permissions-model">Permissions Model</h1>
<p>Gitea's authorization system layers three concepts on top of each other: a coarse
<strong><code>AccessMode</code></strong> enum (<code>models/perm</code>), a per-repository <strong>cached access table</strong>
(<code>models/perm/access</code>), and a <strong>unit-aware <code>Permission</code></strong> struct that is computed on-demand for
every request and combines repo units, collaborators, and organization teams. This page walks
through all three layers.</p>
<p>Source: <code>models/perm/access_mode.go</code>, <code>models/perm/access/</code>, <code>models/unit/</code>.</p>
<h2 id="layer-1-accessmode">Layer 1 — <code>AccessMode</code><a href="#layer-1-accessmode" class="heading-anchor" aria-label="Link">#</a></h2>
<p><code>models/perm/access_mode.go</code> defines the single ordered scale used everywhere in Gitea to
express "how much can this actor do":</p>
<pre class="highlight"><code class="language-go">type AccessMode int

const (
    AccessModeNone AccessMode = iota // 0: no access

    AccessModeRead  // 1: read access
    AccessModeWrite // 2: write access
    AccessModeAdmin // 3: admin access
    AccessModeOwner // 4: owner access
)</code></pre>
<p>Because the values are ordered integers, comparisons like <code>mode &gt;= perm.AccessModeWrite</code> are
used pervasively to test "at least" a given level. <code>ParseAccessMode(s, allowed...)</code> converts the
string forms used in API payloads (<code>"read"</code>, <code>"write"</code>, <code>"admin"</code>) back into the enum,
optionally restricting to a whitelist of <code>allowed</code> values (<code>"owner"</code> is intentionally excluded
from string parsing — it's an internal-only level, never settable via user input).</p>
<h2 id="layer-2-the-access-cache-table">Layer 2 — The <code>Access</code> Cache Table<a href="#layer-2-the-access-cache-table" class="heading-anchor" aria-label="Link">#</a></h2>
<p><code>models/perm/access/access.go</code> maintains a <strong>denormalized cache table</strong> (<code>Access</code>) that stores
the maximum access mode a specific user has on a specific repository, so that hot-path
permission checks don't need to join collaborators + teams + team-units on every request.</p>
<pre class="highlight"><code class="language-go">type Access struct {
    ID     int64 `xorm:"pk autoincr"`
    UserID int64 `xorm:"UNIQUE(s)"`
    RepoID int64 `xorm:"UNIQUE(s)"`
    Mode   perm.AccessMode
}</code></pre>
<p>Important: <code>Access</code> does <strong>not</strong> cover the repository owner themself (owner access is implicit,
computed as <code>AccessModeOwner</code> whenever <code>userID == repo.OwnerID</code>) — only other users
(collaborators or organization-team members) get rows here.</p>

<p><code>refreshAccesses</code> is the core diffing routine: it computes a desired <code>accessMap[userID] =
maxAccessMode(...)</code>, compares it against existing <code>Access</code> rows, and performs minimal
insert/update/delete operations rather than "delete all, re-insert all" — important for repos
with many collaborators.</p>
<p><code>minModeToKeep</code> logic: for a <strong>public, non-org-owned repo</strong>, any access mode below <code>Write</code> isn't
persisted (read access is already implicit for public repos, so storing it would be redundant);
for <strong>private repos or org-owned repos</strong>, the threshold drops to <code>Read</code> since nothing is implicit.</p>
<h3 id="accesslevelctx-user-repo"><code>accessLevel(ctx, user, repo)</code><a href="#accesslevelctx-user-repo" class="heading-anchor" aria-label="Link">#</a></h3>
<p>The core lookup: returns <code>AccessModeRead</code> for any repo that is fully public (or, for restricted
users, public-and-owner-is-public), <code>AccessModeOwner</code> if <code>userID == repo.OwnerID</code>, otherwise
looks up the cached <code>Access</code> row (defaulting to whatever public-read applies).</p>
<h2 id="layer-3-unit-aware-permission">Layer 3 — Unit-Aware <code>Permission</code><a href="#layer-3-unit-aware-permission" class="heading-anchor" aria-label="Link">#</a></h2>
<p>The <code>Access</code> table gives a single access mode for a whole repository, but real authorization
needs to be <strong>per-feature</strong> (a user might have <code>Write</code> on Issues but only <code>Read</code> on Code, e.g. an
external triager). This is modeled by <code>Permission</code> in <code>models/perm/access/repo_permission.go</code>.</p>
<pre class="highlight"><code class="language-go">type Permission struct {
    AccessMode perm_model.AccessMode // the "baseline" mode (repo-wide, e.g. owner/collaborator mode)

    units     []*repo_model.RepoUnit
    unitsMode map[unit.Type]perm_model.AccessMode // per-unit override (from team grants)

    everyoneAccessMode  map[unit.Type]perm_model.AccessMode // min mode for any signed-in user
    anonymousAccessMode map[unit.Type]perm_model.AccessMode // min mode for anonymous visitors
}</code></pre>
<h3 id="resolving-a-units-effective-access-mode">Resolving a unit's effective access mode<a href="#resolving-a-units-effective-access-mode" class="heading-anchor" aria-label="Link">#</a></h3>
<pre class="highlight"><code class="language-go">func (p *Permission) UnitAccessMode(unitType unit.Type) perm_model.AccessMode {
    if m, ok := p.unitsMode[unitType]; ok {
        return util.Iif(p.AccessMode &gt;= perm_model.AccessModeAdmin, p.AccessMode, m)
    }
    unitDefaultAccessMode := p.AccessMode
    unitDefaultAccessMode = max(unitDefaultAccessMode, p.anonymousAccessMode[unitType])
    unitDefaultAccessMode = max(unitDefaultAccessMode, p.everyoneAccessMode[unitType])
    hasUnit := slices.ContainsFunc(p.units, func(u *repo_model.RepoUnit) bool { return u.Type == unitType })
    return util.Iif(hasUnit, unitDefaultAccessMode, perm_model.AccessModeNone)
}</code></pre>
<p>Rules encoded here:</p>
<ol>
<li>If a <strong>per-unit override</strong> exists (from a team grant via <code>TeamUnit</code>), use it — <em>unless</em> the
   user's baseline is already <code>Admin</code>/<code>Owner</code>, in which case the higher baseline wins (an admin
   can't be downgraded by a narrower team grant).</li>
<li>If there's no per-unit override, fall back to <code>max(baseline, anonymousAccessMode[unit],
   everyoneAccessMode[unit])</code> — this is how a <code>RepoUnit.AnonymousAccessMode</code> /
   <code>EveryoneAccessMode</code> setting (e.g. "let anyone read the Wiki") grants access even to users who
   otherwise have no explicit relationship to the repo.</li>
<li>But only if the repository actually <strong>has</strong> that unit enabled at all (<code>hasUnit</code>) — a disabled
   unit is always <code>AccessModeNone</code> regardless of overrides.</li>
</ol>
<p>Convenience wrappers: <code>CanAccess</code>, <code>CanAccessAny</code>, <code>CanRead</code>, <code>CanReadAny</code>, <code>CanWrite</code>,
<code>CanReadIssuesOrPulls(isPull)</code>, <code>CanWriteIssuesOrPulls(isPull)</code>, <code>IsOwner()</code>, <code>IsAdmin()</code>,
<code>HasAnyUnitAccess()</code>, <code>HasAnyUnitPublicAccess()</code>, <code>ReadableUnitTypes()</code>.</p>
<h3 id="finalprocessrepounitpermission-applying-public-access-overlays"><code>finalProcessRepoUnitPermission</code> — applying public-access overlays<a href="#finalprocessrepounitpermission-applying-public-access-overlays" class="heading-anchor" aria-label="Link">#</a></h3>
<p>After the baseline <code>Permission</code> is computed, <code>finalProcessRepoUnitPermission</code> overlays
<code>AnonymousAccessMode</code>/<code>EveryoneAccessMode</code> from each <code>RepoUnit</code> (via <code>applyPublicAccessPermission</code>,
which is a no-op when <code>setting.Repository.ForcePrivate</code> is set instance-wide) and then <strong>prunes</strong>
<code>perm.units</code> down to only the units the user can reach through some mode (explicit unitsMode,
anonymous overlay, or everyone overlay) — this keeps <code>HasAnyUnitAccess</code>/<code>ReadableUnitTypes</code> cheap
and accurate.</p>
<h3 id="computing-permission-for-a-real-request-getindividualuserrepopermission">Computing permission for a real request — <code>GetIndividualUserRepoPermission</code><a href="#computing-permission-for-a-real-request-getindividualuserrepopermission" class="heading-anchor" aria-label="Link">#</a></h3>
<p>This is the main entry point (wrapped by <code>GetDoerRepoPermission</code>, which additionally detects
Actions-task "virtual users" and routes to <code>GetActionsUserRepoPermission</code> instead):</p>
<pre class="mermaid">flowchart TD
    Start([GetIndividualUserRepoPermission]) --> LoadUnits[repo.LoadUnits]
    LoadUnits --> AnonPrivate{user==nil AND repo.IsPrivate?}
    AnonPrivate -->|yes| NoneA[AccessMode = None, return]
    AnonPrivate -->|no| CheckCollab[IsCollaborator?]
    CheckCollab --> OwnerVisible{Owner visible to doer OR isCollaborator?}
    OwnerVisible -->|no| NoneB[AccessMode = None, return]
    OwnerVisible -->|yes| AnonPublic{user == nil?}
    AnonPublic -->|yes| ReadA[AccessMode = Read, return]
    AnonPublic -->|no| SuperUser{user.IsAdmin OR user.ID==repo.OwnerID?}
    SuperUser -->|yes| OwnerA[AccessMode = Owner, return]
    SuperUser -->|no| AccessLvl[accessLevel: read cached Access table]
    AccessLvl --> IsOrgOwned{repo.Owner.IsOrganization?}
    IsOrgOwned -->|no| ReturnPlain[return plain user AccessMode]
    IsOrgOwned -->|yes| MinMode[AccessMode = max(AccessMode, minAccessMode for public repo)]
    MinMode --> GetTeams[GetUserRepoTeams: teams granting access to this repo]
    GetTeams --> NoTeams{no teams?}
    NoTeams -->|yes| ReturnOrg[return]
    NoTeams -->|no| OwnerTeam{any team HasAdminAccess?}
    OwnerTeam -->|yes| OwnerB[AccessMode = Owner, unitsMode = nil, return]
    OwnerTeam -->|no| PerUnit[compute unitsMode per RepoUnit from each team's UnitAccessModeEx]
    PerUnit --> Finalize[finalProcessRepoUnitPermission: overlay anonymous/everyone modes, prune units]
    Finalize --> Done([Permission ready])</pre>
<p>Key special cases baked into the flow:</p>
<ul>
<li><strong>Site admins</strong> and the <strong>repo owner</strong> always get <code>AccessModeOwner</code>, bypassing unit checks
  entirely.</li>
<li>Users <strong>blocked from viewing a private owner</strong> (<code>organization.HasOrgOrUserVisible</code>) get <code>None</code>
  even if they're technically a collaborator-adjacent case is handled by checking
  <code>isCollaborator</code> as an override.</li>
<li>For org-owned repos, if <strong>any</strong> team the user belongs to has <code>HasAdminAccess()</code> (i.e. is the
  Owners team or another admin-mode team), the whole <code>unitsMode</code> map is cleared and
  <code>AccessMode = Owner</code> — admin teams always get full access to every unit, sidestepping
  per-unit team grants.</li>
<li>Otherwise, <code>unitsMode[u.Type]</code> is the max across all the user's teams' <code>UnitAccessModeEx</code>
  results for that unit type (<code>Team.UnitAccessModeEx</code> reads the <code>TeamUnit</code> row, falling back to
  the team's overall <code>AccessMode</code> when <code>HasAdminAccess()</code>).</li>
</ul>

      navigator.clipboard.writeText(text).then(function(){btn.textContent='Copied!';setTimeout(function(){btn.textContent='Copy';},2000);});
    });
    pre.appendChild(btn);
  });
  // Back to top
  var btt=document.getElementById('back-to-top');
  if(btt){
    window.addEventListener('scroll',function(){btt.style.display=window.scrollY>300?'flex':'none';});
    btt.addEventListener('click',function(){window.scrollTo({top:0,behavior:'smooth'});});
  }
  // TOC active scroll tracking
  var tocLinks=document.querySelectorAll('.toc-aside a[data-anchor]');
  if(tocLinks.length>0){
    var headingEls=[];
    tocLinks.forEach(function(l){var el=document.getElementById(l.dataset.anchor);if(el)headingEls.push({el:el,link:l});});
    var tocAside=document.querySelector('.toc-aside');
    var onScroll=function(){
      var scrollPos=window.scrollY+80;
      var active=null;
      for(var i=0;i<headingEls.length;i++){if(headingEls[i].el.offsetTop<=scrollPos)active=headingEls[i];}
      tocLinks.forEach(function(l){l.classList.remove('toc-active');});
      if(active){
        active.link.classList.add('toc-active');
        // Scroll active link into view within the TOC panel, not the page
        if(tocAside){
          var linkTop=active.link.offsetTop-tocAside.offsetTop;
          var visibleTop=tocAside.scrollTop;
          var visibleBottom=visibleTop+tocAside.clientHeight;
          if(linkTop<visibleTop+40||linkTop>visibleBottom-40){
            tocAside.scrollTop=linkTop-tocAside.clientHeight/2;
          }
        }
      }
    };
    window.addEventListener('scroll',onScroll);
    onScroll();
    // Prevent TOC links from scrolling the TOC panel to top on click
    tocLinks.forEach(function(l){
      l.addEventListener('click',function(e){
        e.preventDefault();
        var anchor=l.dataset.anchor;
        var target=document.getElementById(anchor);
        if(target){target.scrollIntoView({behavior:'smooth',block:'start'});}
      });
    });
  }
  // Persist sidebar scroll position across page navigations
  var sidebarEl=document.querySelector('nav.sidebar');
  if(sidebarEl){
    var sidebarKey='sasva-sidebar-scroll';
    // Restore scroll position on page load
    var savedScroll=sessionStorage.getItem(sidebarKey);
    if(savedScroll){sidebarEl.scrollTop=parseInt(savedScroll,10);}
    // Save scroll position before navigating away
    document.querySelectorAll('#sidebar-nav-links a').forEach(function(a){
      a.addEventListener('click',function(){
        sessionStorage.setItem(sidebarKey,String(sidebarEl.scrollTop));
      });
    });
    // Also scroll active item into view on load
    var activeLink=sidebarEl.querySelector('a.active');
    if(activeLink&&!savedScroll){
      var linkOffset=activeLink.offsetTop-sidebarEl.offsetTop;
      sidebarEl.scrollTop=Math.max(0,linkOffset-sidebarEl.clientHeight/2);
    }
  }
})();
